Why This Beats A Plain Map

The activity guide ties each marker to a completion priority and evidence label. That means users can clear Leonida by confidence level: confirmed first, expected next, pending once launch data arrives.

Activity FAQ

Will all activities count toward 100%?

No one should assume that yet. The page tracks likely categories, but each activity needs launch verification before it is marked required.

What gets added after launch?

Rules, start locations, rewards, medals, completion percentage impact, best vehicles, and map routes should be added first.
